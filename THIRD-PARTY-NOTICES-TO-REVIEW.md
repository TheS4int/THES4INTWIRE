# Third-party notices — REVIEW REQUIRED BEFORE PUBLISHING

THES4INTWIRE uses Rust, Tauri 2, JavaScript dependencies and browser platform APIs. Dependencies retain their own licenses even though the THES4INTWIRE desktop application is proprietary.

**Publisher action:** Generate and review an SBOM/license inventory from the **private** Rust/Node workspace; provide legally required notices with distributions. This repository contains **no verified complete third-party notice inventory**. Check any distributed icon/banner licenses and rights as well.

Suggested private-project audits: `cargo license` / `cargo about`, and `npm ls --all` with license inspection. Do not treat automated output as a complete legal review.
