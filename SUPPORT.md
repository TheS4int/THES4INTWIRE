# Support and bug reports

Open a GitHub issue with the application version, Windows version, the affected feature, steps to reproduce, and whether the problem occurs after a fresh application start.

For ETW issues report the displayed event/sample counters and whether other monitoring tools are running, but do not include private addresses or sensitive logs.

For browser issues report browser name/version and whether the extension is paired; do not include tab URLs or credentials.

For API reputation issues report HTTP status and provider name, never the API key.
