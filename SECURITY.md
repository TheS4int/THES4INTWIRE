# Security Policy

## Supported versions
Security fixes are planned for the latest available release only (currently v1.24.0 release candidate).

## Reporting vulnerabilities
Do not publish exploit details, private network information or API keys in a public issue. If this repository enables **GitHub private vulnerability reporting**, use **Security → Report a vulnerability**. Otherwise request a private contact channel via an issue that contains **no sensitive details**.

THES4INTWIRE observes network/process metadata. It is not an antivirus, EDR product or definitive malware detector. It does not provide warranty or guaranteed detection.
