# Changelog

## v1.24.0 — Threat Reputation (release candidate, 2026-11-12)
- Added on-demand VirusTotal IP reputation results.
- Added on-demand AbuseIPDB confidence and report data.
- Added a clearly labeled, heuristic 0–100 indicator, distinct from confirmed security findings.
- Preserved local IOC watchlist and process/IP matching.
- Includes prior Browser Intelligence, per-tab observed transfer indicators and both Neon themes.

## v1.23.0 — Browser Tab Traffic
- Added observed per-tab receive/send metrics, browser-specific availability limits.

## v1.22.0 — Local IOC Intelligence
- Added local IP/CIDR watchlist matching and process association.

## v1.21.0 — Browser Intelligence
- Added local browser extension bridge for Chromium browsers and Firefox.

## v1.20.0 — Process Identification
- Added application metadata lookup.

## v1.19.0 — Network Intelligence
- Added RDAP network-owner lookups and ETW session management improvements.

## Earlier versions
- PTR DNS, ETW per-process/per-destination traffic, endpoint list, dual skins and live adapter monitoring.

> Detailed internal development history is maintained in the private project. The above is a user-facing summary, not a claim of comprehensive security validation.
